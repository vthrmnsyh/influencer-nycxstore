Analisis Influencer TikTok @NYCXSTORE
Sistem pendukung keputusan untuk mengidentifikasi influencer potensial menggunakan Graph Neural Networks (GNN) dan Natural Language Processing (NLP).

📌 Deskripsi Proyek
Proyek ini dikembangkan sebagai bagian dari Tugas Akhir untuk menganalisis perilaku konsumen dan mengidentifikasi Key Opinion Leaders (KOL) pada akun TikTok @NYCXSTORE. Sistem ini menggabungkan teknik Social Network Analysis (SNA) dan Deep Learning untuk memberikan visualisasi jaringan interaktif serta rekomendasi influencer berdasarkan skor keterlibatan (engagement score).

🛠 Teknologi yang Digunakan
Python 3.10+

Framework Web: Streamlit

Deep Learning: PyTorch & PyTorch Geometric (GraphSAGE & GAT)

NLP: IndoBERT (untuk analisis sentimen komentar)

Visualisasi: Plotly & NetworkX

📊 Fitur Utama
Ranking Influencer: Menampilkan daftar top influencer berdasarkan skor GNN dan SNA.

Analitik SNA: Visualisasi metrik sentralitas (PageRank, Betweenness Centrality) pengguna.

Jaringan Graf: Visualisasi interaktif jaringan hubungan antar-pengguna menggunakan Graph Neural Networks.

Training GNN: Pemantauan performa model melalui Loss Curve secara real-time.
